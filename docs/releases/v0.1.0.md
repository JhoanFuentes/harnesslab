# HarnessLab v0.1.0

Initial public release of a durable AI agent runtime and behavioral evaluation
lab for incident diagnosis.

## Included

- Python 3.11+ runtime with no third-party runtime dependencies.
- Durable SQLite sessions, checkpoints, effect receipts and audit replay.
- Scoped tools, exact-action approvals, evidence gates and usage budgets.
- Explicit recovery behavior for crashes and uncertain model-request usage.
- Scripted conformance provider and optional OpenAI Responses adapter.
- Twelve synthetic scenarios, four harness profiles and an offline HTML report.
- Architecture decisions, threat model, case study, and English/Spanish guides.

## Validation

69 automated tests passed locally and in GitHub CI on Ubuntu/Windows with
Python 3.11/3.13. [Observed CI run](https://github.com/JhoanFuentes/harnesslab/actions/runs/43806869285).
The included scripted comparison has 48 runs:
baseline 7/12, hardened 12/12, no-evidence-gate 9/12, no-retries 11/12.
The report includes the dataset, source and configuration hashes.

These are runtime contract checks, not live LLM accuracy measurements. No live
provider evaluation is included. Local simulated effects do not establish
exactly-once guarantees for external APIs. See SECURITY.md and docs/EVALUATION.md.

## Run

```sh
python -m harnesslab demo --output runs/demo
python -m unittest discover -s tests -v
```

Open `runs/demo/report.html` for the interactive report. No API key is needed.

Or [explore the public report](https://jhoanfuentes.github.io/harnesslab/) without
installing anything. It includes per-case outcomes, grading reasons and traces.
