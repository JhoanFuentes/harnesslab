# HarnessLab v0.2.0 — Repeated agent evaluations and cost per successful task

An agent evaluation can look affordable when it reports only successful runs,
or look reliable when repeated trials of the same task are treated as independent
evidence. This release makes the study protocol and those denominators explicit.

## What changed

- `study-plan` freezes datasets, rubric, source/prompt hashes, model settings,
  prices and a seeded randomized schedule without network calls.
- `study-run` supports repeated model/profile comparisons, fresh durable sessions,
  per-call response metadata and separate output directories.
- Cost per successful task includes **all attempted tasks**, including failures.
  Unknown usage and zero-success cases stay unavailable instead of becoming zero.
- Task-cluster bootstrap intervals, paired profile comparisons, per-case
  consistency, latency percentiles and missing-slot accounting are included.
- Cache-read pricing, ambiguous-usage handling and interruption regressions have
  offline coverage. Unpriced cache writes stop rather than silently undercount.
- A separate public synthetic suite contains 4 development and 12 test cases,
  with fixed aliases, abstentions, distractors and injection scenarios.

## Evidence and operating limits

The extension passed **140 local tests** before publication. GitHub Actions
checks Windows/Ubuntu with Python 3.11/3.13, the historical artifact, a fresh
scripted demo, network-free study planning and the public-file allowlist.
See [the validation record](../VALIDATION.md) for observed workflow results.

**No live model evaluation was executed.** The two-model, two-profile, five-trial
configuration describes **240 planned attempts**, not model-performance results.
Models and current prices remain unset. Spend limits use observed usage, so a
crossing response may exceed the threshold; they are not provider billing caps.

The original 48-run scripted report and SQLite traces are preserved unchanged,
with a frozen runtime source snapshot. Their scores remain conformance evidence.
The versioned planning preview is published separately at `/harnesslab/study/`.

## Reproduce without credentials

```sh
python -m unittest discover -s tests -v
python -m harnesslab demo --output runs/review
python -m harnesslab study-plan --config studies/live.example.json --output runs/study-plan.json
python scripts/verify_example.py
```

Python 3.11+; standard-library runtime. New inference requires explicit execution,
model/pricing configuration and credentials. Review [the full protocol](../LIVE_STUDY.md)
before interpreting or publishing actual model results.
