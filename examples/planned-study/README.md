# Unexecuted planning artifacts

The active **v0.2.0** preview is [v0.2.0/plan.html](v0.2.0/plan.html), with its
[frozen protocol](v0.2.0/plan.json). It describes planned attempts only: model
snapshots and rates remain unset, and no real-model results are included.

The `plan.json` and `plan.html` files at this directory's top level preserve the
earlier local draft from before the publication version bump. Its runtime hash
intentionally differs from v0.2.0; it is historical planning context, not an
executable plan for the current source.

For an actual experiment, configure the study and generate a new plan using the
[execution guide](../../docs/LIVE_STUDY.md). Do not edit a frozen plan in place.
